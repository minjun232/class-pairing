자리배치 사용설명서

교실에서 사용하기 전에 프로그램을 실행해 명단을 먼저 만들어 주세요. 교사 조건을 적을 수 있는 파일(Settings.ini)이 생성됩니다.

1. 자리배치는 어떤 프로그램인가요

  • "철수랑 영희 멀리", "민수 시력 안 좋음"처럼 평소 말투로 조건을 적으면, 프로그램 안의 작은 인공지능(AI)이 뜻을 읽고 조건을 지키는 자리를 무작위로 만듭니다.
  • 결과는 가려진 채 나오고, 전자칠판에서 한 명씩 뒤집어 공개합니다.
  • 인터넷, 설치, 회원가입이 필요 없습니다. 선생님이 적은 조건(교사 조건)은 화면 어디에도 나오지 않습니다.

2. 처음 준비하기 (압축 풀기)

  1. 내려받은 zip 파일을 USB 또는 D드라이브에 복사합니다.
  2. 파일을 마우스 오른쪽 버튼으로 누르고 모두 압축 풀기... → 압축 풀기를 누르면 자리배치 폴더가 생깁니다.
바탕화면이나 C드라이브에는 두지 마세요. 학교 컴퓨터는 다시 켜면 C드라이브가 처음 상태로 돌아가는 경우가 많아, 반 정보와 직전 자리표가 사라질 수 있습니다.

폴더 안에 들어 있는 것

이름설명
자리배치.exe프로그램(파란 책상 아이콘). 선생님이 누르는 파일은 이것 하나입니다.
사용설명서.pdf지금 보고 있는 설명서입니다.

3. 프로그램 켜기

  1. 자리배치.exe를 두 번 누릅니다.
  2. 처음 실행할 때 파란 창 "Windows의 PC 보호"가 나오면 추가 정보를 누르고 실행을 누릅니다.
  3. 백신(V3, 알약 등)이 경고하면 "허용" 또는 "예외로 등록"을 선택합니다.
켜자마자 위쪽에 작게 "모델 불러오는 중…"이 보입니다. USB가 느리면 1분 정도 걸리며, 기다리는 동안에도 다른 설정은 할 수 있습니다.

4. 반 만들고 명단 적기

  1. 첫 화면 아래 칸에 반 이름(예: 2-3)을 적고 반 추가를 누릅니다. 새 반이 바로 열리고 명단 화면이 나옵니다.
  2. 남 칸에 남학생, 여 칸에 여학생 이름을 한 줄에 한 명씩 적습니다. 엑셀이나 나이스에서 이름을 복사해 붙여 넣어도 됩니다.
  3. 저장을 누릅니다. 다른 화면으로 넘어가도 자동으로 저장됩니다. 저장하면 나오는 교실 설정으로를 누르면 다음 장으로 넘어갑니다.
명단은 반 폴더의 명단.xlsx에 저장됩니다. 엑셀로 직접 고쳐도 됩니다(A열 남, B열 여). 고친 뒤에는 엑셀을 닫아 주세요.
이름이 같은 학생(동명이인)은 반에서 부르는 그대로 구분해 적습니다. 예: 김민수 A / 김민수 B, 또는 김민수1 / 김민수2
조건이나 요청에도 같은 표기(민수 A, 민수1)를 써 주세요. 그냥 "민수"라고만 쓰면 누구인지 알 수 없어 그 조건은 건너뜁니다.

5. 교사 조건 적기 (Settings.ini)

교사 조건은 항상 가장 먼저 지켜지는 조건입니다. 학생이 눈치채지 못하도록 평범한 설정 파일 이름을 붙였습니다.

4장의 명단을 먼저 저장한 뒤 조건을 적어 주세요. 조건에 쓴 이름은 명단과 맞춰 읽으므로, 명단에 없는 학생의 조건은 지켜지지 않습니다.
  • 반 폴더의 Settings.ini를 두 번 눌러 메모장으로 엽니다. 앱을 고르라고 나오면 메모장을 고르세요.
  • 한 줄에 조건 하나씩 평소 말투로 적고 저장(Ctrl + S)합니다.
  • 맨 위 [General] 줄은 그대로 두고, ;로 시작하는 줄은 메모로 쓸 수 있습니다.

교실 방향 (꼭 읽어 주세요)

모든 방향은 학생이 칠판을 바라본 방향입니다.
  • 1줄이 칠판 바로 앞 줄, 1열이 창문 쪽(왼쪽) 열입니다.
  • 프로그램은 교실을 이렇게 알고 있습니다: 칠판 앞쪽 가운데, 교탁 앞쪽 창문 쪽, 창문 왼쪽 벽, 앞문·뒷문 오른쪽 벽.
  • 실제 교실이 다르거나(예: 창문이 오른쪽) 에어컨·사물함처럼 목록에 없는 곳은 "1열", "6열"처럼 숫자로 적어 주세요.

"앞쪽"의 기준 바꾸기 (필요할 때만)

Settings.ini에 아래처럼 숫자를 적으면 기준이 바뀝니다.

앞쪽 = 3     ← 앞쪽을 앞 3줄로
뒤쪽 = 1     ← 뒤쪽을 맨 뒷줄만
창가 = 2     ← 창가를 왼쪽 2열로
복도 = 2     ← 복도 쪽을 오른쪽 2열로
알아듣지 못하는 조건: "키 큰 애들 뒤로", "친한 애들끼리"처럼 이름이 없는 조건은 처리할 수 없습니다. 이름을 직접 적어 주세요. 알아듣지 못했거나 지킬 수 없는 조건은 아무 표시 없이 무시될 수 있습니다(학생들 앞에서 조건이 드러나지 않도록). 배치 결과가 조건과 다르면 9장의 편집으로 직접 자리를 바꿔 주세요.

6. 교실 모양 정하기

반을 고르고 시작을 누르면 교실 화면이 나옵니다. 바꾼 내용은 반마다 자동으로 저장됩니다.

  • 배치: 짝(책상마다 2명) / 단독(1명씩) / 모둠(− +로 인원 조절, 기본 4명, 최소 3명)
  • 줄 열: 줄은 앞에서 뒤로, 열은 왼쪽에서 오른쪽으로 몇 개인지입니다.
    • 짝에서 열은 학생 자리 수입니다. 책상 3개가 나란히 있으면 6열입니다.
    • 모둠에서 줄·열은 모둠의 줄·열 수입니다.
  • 성별: 짝은 무관 / 남녀 짝, 모둠은 무관 / 남녀 고르게. (단독에는 없습니다)
  • 칸 누르기: 칸을 누를 때마다 자리 → 빈자리 → 통로로 바뀝니다. 고장 난 책상은 빈자리, 책상이 없는 곳은 통로로 두세요.
  • 학생보다 자리가 많으면 뒤쪽 자리부터 비워 둡니다. 자리가 모자라면 "자리가 N개 부족해요"가 나옵니다.

7. 자리 배치 시작하기 (학생 요청)

명단과 교실은 한 번 정해 두는 준비이고, 자리를 바꿀 때마다 하는 진행은 위쪽 자리 배치 시작에서 출발합니다. 진행 중에는 위쪽에 지금 단계(요청, 배치, 공개, 확정)가 표시됩니다.

  1. 위쪽 자리 배치 시작을 누르면 학생 요청 화면이 나옵니다. 명단이 없거나 자리가 모자라면 버튼이 흐리게 바뀌어 누를 수 없습니다.
  2. 요청이 있는 학생만 이름 오른쪽 칸에 적습니다. 예: 창가 자리, 지훈이랑 짝, 뒷문 근처는 싫어요
  3. 요청이 없으면 그냥 다음 장으로 넘어가세요. 저장을 미리 누르면 요청을 먼저 읽어 두어 배치가 빨라집니다.
  4. 교실 설정을 고치려면 이전을 누릅니다. 적어 둔 요청은 그대로 남습니다.
학생 요청은 교사 조건과 남녀 짝 설정 다음으로 지켜지며, 모두 지킬 수 없으면 특정 학생만 손해 보지 않게 고르게 양보합니다. 요청은 파일로 저장되지 않고 프로그램을 끄면 사라집니다.

8. 자리 배치하고 공개하기

  1. 요청 화면 아래 자리 배치를 누릅니다.
  2. 모든 자리가 ?로 가려진 채 나옵니다. 위쪽에 "읽는 중…"이 보이는 동안(조건과 요청을 읽는 중)에는 버튼이 흐리게 바뀌어 누를 수 없습니다.
  3. 공개하는 방법은 두 가지입니다.
    • 오른쪽 이름을 누르면 → 그 학생의 자리가 뒤집힙니다.
    • 자리를 누르면 → 그 자리에 앉은 학생이 나옵니다.
  4. 전체 공개를 누르면 한 번에 모두 보입니다. 다시 배치를 누르면 새로 배치합니다.

공개하다가 명단이나 교실을 눌러도 배치는 그대로 남아 있습니다. 위쪽 배치로 돌아가기를 누르면 이어서 공개할 수 있습니다.

지켜지는 순서: ① 교사 조건 → ② 남녀 짝·남녀 고르게 → ③ 학생 요청 → ④ 직전 짝과 다시 짝 되지 않기 → ⑤ 무작위
위에 있는 조건과 부딪히면 아래 조건은 꼭 필요한 만큼만 양보합니다. 교사 조건끼리 부딪히거나 교실 모양 때문에 지킬 수 없는 조건은 무시하고 배치합니다(화면에는 아무 표시도 나오지 않습니다).

9. 자리 바꾸기 (편집)

모든 자리를 공개하면 편집 버튼이 나옵니다. 편집을 누르고 두 자리를 차례로 누르면 두 학생의 자리가 맞바뀝니다(빈자리와도 바꿀 수 있습니다). 다 바꾸면 편집 끝을 누릅니다. 선생님이 직접 바꾼 자리는 조건 검사를 하지 않습니다.

10. Word로 저장하기 (확정)

  1. Word로 저장을 누르면 "저장하면 자리가 확정되어 더 이상 수정할 수 없어요."가 나옵니다.
  2. 확정·저장을 누르면 반 폴더(반 → 2-3)에 자리배치_날짜.docx가 저장됩니다. 알림의 폴더 열기를 누르면 바로 열 수 있습니다.
  3. Word 표는 교사 시점(교탁에서 학생을 바라본 방향)으로 그려집니다. 한글(HWP)에서도 열립니다.
  4. 확정한 자리는 다음 배치 때 "직전 짝"으로 쓰여, 같은 짝이 다시 되지 않도록 합니다.

지난번 자리 다시 보기

확정한 자리는 반마다 기억해 둡니다. 교실 화면에서 현재 배치 보기를 누르면 마지막으로 확정한 자리가 그대로 나옵니다. 여기서 Word로 저장을 누르면 그 자리표를 다시 저장하고, 새로 배치를 누르면 학생 요청 화면부터 새로 시작합니다.

11. 끝내기

오른쪽 위 끝내기를 누릅니다. 저장되지 않는 내용(입력한 학생 요청, 확정하지 않은 자리)이 있으면 확인 창이 나옵니다.

12. 이럴 땐 이렇게 하세요

상황해결 방법
"모델 불러오는 중…"이나 "읽는 중…"이 오래 계속돼요USB가 느리거나 컴퓨터가 오래되면 1~2분 걸릴 수 있습니다. 폴더를 D드라이브로 복사해 실행하면 빨라집니다. 교사 조건은 한 번 읽으면 기억하므로 다음부터는 빠릅니다.
교사 조건이 지켜지지 않았어요조건끼리 부딪히거나(예: 두 학생을 모두 1줄 1열에), 교실 모양 때문에 지킬 수 없거나, 문장을 잘못 알아들으면 그 조건은 무시됩니다. 모두 공개한 뒤 편집으로 직접 자리를 바꿔 주세요.
"조건을 해석할 모델 파일이 없어요"system 폴더의 파일이 지워졌습니다. 프로그램을 다시 내려받아 주세요.
"이 컴퓨터에서는 조건을 해석할 수 없어요."아주 오래된 컴퓨터는 인공지능을 실행할 수 없습니다. 다른 컴퓨터에서 한 번 배치하면 교사 조건을 기억하므로, 같은 USB를 이 컴퓨터에 꽂으면 교사 조건은 지켜집니다(학생 요청은 반영되지 않습니다).
"명단.xlsx를 읽을 수 없어요" / "명단을 저장할 수 없어요"엑셀에서 명단을 닫고 다시 시도하세요.
반 폴더 이름을 바꿨더니 교실 모양이 처음으로 돌아갔어요교실 모양과 직전 자리는 반 이름으로 기억합니다. 이름을 바꾸면 새로 시작합니다.
